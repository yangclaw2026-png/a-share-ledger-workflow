# 数据源、引用规范与历史对比铁律

主技能 `a-share-investment-workflow` 的共享参考文件，供第2–7步子技能按需引用。

## 1. 日期纪律

先 `date` 确认今天。周末/节假日明确说明“行情截至最近交易日”，不要用陈旧数据冒充实时。

## 1b. 逐股核实与交叉验证

本工作流固定要求（写入记忆，长期有效）：

1. **先确认当天日期**，再逐一核实每只标的当日数据（收盘价、涨跌幅、资金流向等），不要用上一交易日或搜索摘要里的数字代替。
2. **交叉验证**：同一关键数字尽量由两个独立来源比对（如行情接口 + 交易所/公司公告，或两个 AI 分别取数后对比）。**数据不一致时不要自己挑一个**——列出两套口径并标注差异来源，交给用户判断。
3. **确认无误后再分析**。数据没核实完，不要先给结论。

当数据源本身存疑（如接口返回 0 值、字段缺失、页面为快照而非实时）时，先确认源的可用性，再谈结论。

## 1c. 双 AI 独立取数

用户要求“你和 opencode 分别”时，用 `delegate_task` 启动子代理独立取数，两边结果并列比对。**主持人先轻量核准确代码/全称再发任务卡**，避免浪费辩手搜索资源。子代理输出可能 schema 验证失败，直接读文件而非只看返回摘要。

若用户说“不要辩论”，改为表格并排，不展开辩论。

## 2. 数据获取顺序

1. **腾讯行情**（快，适合日K/实时）：
   - `https://qt.gtimg.cn/q=sh600000`（换成你的标的）
   - `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600000,day,START,END,N,qfq（换成你的标的）`
2. **半年报/年报原文**（巨潮资讯网 `static.cninfo.com.cn` PDF）→ 下载后 `pdftotext -layout` 读全文，不要只依赖搜索摘要。
3. `web_search` 补充行业与事件。

## 3. 本环境实测坑

- `web_extract` 默认 SearXNG 后端只能搜索、不能抽取，会失败 → 改用 terminal urllib 下载 PDF + pdftotext。
- akshare 默认未安装 → 腾讯接口够用，不必强装。
- 搜索结果常有无关垃圾页面，务必用 `site:cninfo.com.cn` 或核对 URL 域名。
- pdftotext 输出中数字对齐可能有空格，做逐字校验时要复制原文片段而非重打。

## 4. 引用规范

用 `grounded-citations` 技能（`$HERMES_HOME/skills/research/grounded-citations/scripts/sources.py`）。财报类必须 `--evidence` 逐字校验；摘要用 `--style evidence --replace-in` 自动渲染，**不要手打URL**。

保留来源URL、获取日期、计算口径（复权方式、窗口长度）。

## 5. 历史对比铁律（踩过3次坑）

**做任何“X涨了多少 / Y跌了多少”的对比之前，必须先和用户确认两个参数，不能自己选：**

1. **起点日** —— 用户心里的起点往往和你默认的不同。踩坑实例：用 9/1 和 7/1 当起点得出“光模块没涨”，用户指出正确的是 **8/1**（那一波上涨全在 8 月，起点选晚就整个漏掉）。**同一组数据换起点可得出完全相反结论。**
2. **基准指数** —— 半导体股不能用上证（银行为主）。实测某半导体标的 vs 上证相关仅 0.55，**vs 科创50 高达 0.73**。用错基准会把板块级下跌误判成个股波动。**选基准看持仓的业务属性。**
3. **市场范围** —— 别忘了海外对标。A股半导体/存储的定价参考：韩股（三星/SK海力士）、美股（美光/Amkor/英伟达）、港股（中芯/华虹）。**假期期间海外仍在交易，是 A 股开盘的前瞻。**

**做法：先问“你说的起点是哪个日期、对标哪个指数/标的”，再取数。** 否则白算一遍。

## 6. 全球对标选择

市场环境与产业方向按目标产业扩展到海外重要市场，不限于中国。对标要说明价格、汇率、时区与业务差异；海外走势是证据之一，不自动等同于A股个股的涨跌因果。
