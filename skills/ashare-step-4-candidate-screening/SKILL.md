# 第4步：候选比较与跟踪筛选

主技能 `a-share-investment-workflow` 第4步子技能。对用户选定的标的做四项检查，输出是否进入跟踪。**不合成总分、不排名。**

## When to Use

- 用户在候选池里选定了要进一步评估的标的。
- 已有跟踪标的需要重新判断是否继续跟踪。

## 🔴 执行纪律（本工作流强制·优先级最高）

🔴 **本节优先于本技能其余内容，冲突以本节为准。**

### 收尾自查

- [ ] 上市首年污染检验已做，分位给了两个值
- [ ] 双向核验：支持与反证都写了
- [ ] 扣非占比 / 经营现金流 / 分位成因 三项都查了
- [ ] ROE 周期标签已回看全部完整年度

## 四项检查

1. **业务关联与逻辑**：核实目标产业环节关联及传导链；读年报“主要业务”，不凭印象。
2. **经营证据与可跟踪性**：订单、收入、产能、利润、现金流等可观察指标；关键业务披露不清标“待核实”。
3. **估值与相对表现**：适用估值口径、自身历史与同业比较；对相对落后的二线股查原因和追赶催化——低股价/低倍数/涨幅落后不单独视为机会。
4. **风险与反证**：解释便宜/落后的可能原因、逻辑失效条件；排查基本面恶化、竞争力不足、财务压力等价值陷阱。

## 双向核验（必须做）

- **支持**：业务是否真与用户逻辑相关。
- **反证**：逻辑缺口在哪。常见四类——①“跌得多/离高点久”不是催化；②“海外某类股上涨→本公司上涨”缺传导证明；③公司分类口径可能不含用户以为的业务；④技术面仍偏弱。

## 结论（三选一，不强制选）

- **进入跟踪**：逻辑成立、可跟踪、无致命反证 → 转第5步。
- **待核实/观察**：关键信息缺失 → 列为待核实，给跟进清单。
- **暂不跟踪**：逻辑不成立或价值陷阱风险高 → 记录原因。

进入跟踪不等于现在可以买；本框架先用试行再调整。

## 比较原则

- 同环节横向比较，提供核验数据、差异、风险、证据缺口与待判断问题。
- 不把未验证数字或主观权重伪装成精确排名。
- 做任何“涨了多少/跌了多少”的对比前，先与用户确认起点日、基准指数、市场范围（见主技能下的《数据源、引用规范与历史对比铁律》参考文件）。

## 上市首年污染检验（必做，不可跳过）

任何标的算 PB / PE 历史分位时，**必须同时给出两个值**：含上市首年 与 剔除上市首年。

- 方法：剔除上市后前 365 天，再重算分位。
- 理由：���股上市时净资产基数小，PB 系统性偏高，污染历史分位；样本越短越不稳。
- 判定：变动 >8pt = 重新论证分位结论；3–8pt = 标注；<3pt = 稳定。
- 禁忌：不得只在个别方向做此检验。全库复审曾发现漏做检验导致两处错误：某标的 PB 分位误记（实为更高值），另一标的“剔首年分位不变”记反（实为不降反升）。
- 污染是双向的：某标的剔首年后分位**下降** 9.1pt（更安全），不可预设方向。

## 🔴 低估值分位 ≠ 可入（四次实测反复验证）

| 现象 | 实例 |
|---|---|
| **业绩质量最干净的估值最贵** | 某标的扣非占比 45.6% vs 另一标的 99.2%（后者更贵）|
| **最低分位常与主业脱钩** | 某标的扣非大增但营收微增；某方向多家 PB 分位低但经营现金流全负 |

🔴 **低分位不构成买入理由。** 每只候选必查三项，任一不达标即不得进第5步：
1. **扣非占归母比重** —— 排除一次性损益伪装
2. **经营现金流** —— 排除纸面利润（金融股例外见第5步）
3. **分位成因** —— 是真便宜，还是盈利/净资产口径异常

## 🔴 A1 是四腿，不是两腿

**四条全过**才算 A1 过，漏任何一条都会批量误判：

```
扣非净利 > 0
扣非同比 > 0
经营现金流 > 0
经营现金流同比 > 0     ← 最容易漏的一条
```

**只查前两条的下场**：某方向第4步初始出「十余只进入跟踪」，补齐后**只剩约三分之二 —— 数只被错放**。典型：标的甲扣非同比 +20% 以上看着健康，实为**经营现金流同比 −40% 量级**；标的乙现金流为正，但同比 −30% 以上。

**现金流同比必须自算**：取本期与去年同期的 `NETCASH_OPERATE_PK`，`(cur−prev)/abs(prev)*100`。`cf_prev` 按 `REPORT_DATE` **精确匹配同报告期**（`2026-06-30` 配 `2025-06-30`），不取相邻条。

## 🔴 PE_TTM 为负 ≠ 现在亏损（实测案例）

某标的 PE_TTM 为负 → 初判「亏损」排除。实际 **TTM 滚动窗口含上一年度巨亏，而最新报告期扣非已转正、现金流大增**。

规则：**A1 一律按最新报告期（半年报/季报）判定，不用 TTM**。TTM 是估值指标，不是盈利质量指标。凡初判「亏损」的标的，先看最新报告期是否已扭亏，再下结论。

## 🔴 自写分位脚本后，必须与现成脚本交叉复核

东财 `RPT_VALUEANALYSIS_DET` 的 `sortTypes` 方向决定 `r[-1]` 是哪一天：**`-1`（降序）时 `r[-1]` 是 2018 年第一条**，现有 `scripts/rescreen_candidates.py` 用 `1`（升序）使 `r[-1]` 为最新日。混用时**PB 分位会拿多年前的价格去算**——全表错但不报错（曾实测标的甲算出 1% 量级 vs 正确十余个百分点、标的乙差出数倍）。

纪律：**优先直接复用 `rescreen_candidates.py`（已内置 A1 四腿 + B3 + `--json-out`），别另写一套**；自写了就必须跑 `--codes <新代码>` 与现成脚本逐项对照 PB/PE 分位、扣非占比。

## 估值分位解读纪律

- **PB 分位只作警示，不作否决项。** 主口径＝全样本，🔴 **强制并列近3年分位**，不得只报单一窗口（高 ROE 成长股全样本分位结构性偏高：实测某标的全样本 90.0% vs 近1年 23.6%）。
- **警示带**：🟡 ≥90% ｜ 🔴 ≥98%。**仅标注，不阻断、不改结论。** 依据：实测 PB 高分位对未来 60 日收益**无稳定预测力**，但有明确风险提示价值。某方向曾长期大面积 >90% → 会脱敏，故只作信息展示。
- **PE 分位是识别成长股的关键**：PB 高位 + PE 近1年落到个位数 = 「盈利兑现压估值」（PB = PE × ROE），必须与普通背离区分。
- PE 为负（亏损）时分位无意义，改用 PB 并注明亏损；PE >100x 先查是否被一次性损益扭曲。
- 🔴 **反例（真该排除）**：PE 低来自**一次性收益或周期顶部利润**、扣非与现金流不支持 → 陷阱。**这类由 A1/A2 现金流门槛拦截，不靠估值分位拦截。**
- 结论必须与已研究方向**同口径**横向对比，不得单方向自说自话。

## ROE 周期标签（仅提示不阻断）

回看**上市以来所有完整年度 ROE（加权）**后打标。含义：当期高 ROE 受周期影响大，**不宜线性外推**。

| 标签 | 条件 |
|---|---|
| 🔴 **强周期** | 任一完整年度 ROE < −10% ｜ 或极差 > 60pt ｜ 或 ROE 由负转正年份距今 ≤3 年 |
| 🟡 **波动** | 任一完整年度 ROE < 0（未达 −10%）｜ 极差 30–60pt |
| ⚪ 无 | 从未为负 且 极差 < 30pt |

数据源：东财 F10 `RPT_F10_FINANCE_MAINFINADATA` 年度 `ROEJQ`。
- **只提示，不阻断、不改结论**；标签带入第5步，在台账/状态表显示。
- ⚠️ **无法区分「周期崩塌」与「周期成长」**：某标的极差 69.9pt 被标 🔴，但它从未亏损、ROE 单向走高。标签的作用是提醒「ROE 非稳态」，**不是判定质地差** —— 必须与现金流、扣非质量合读。

## 估值消化检验（展示项）

输出 **PE 分位（近3年口径）**供第5步判断。**本步只输出、不判定**（买入属第5步）。判读：PE近3年 ≤50% 且扣非占归母 ≈100% → 盈利已实质消化估值；PE 低但扣非弱 → 属上节反例。

## 周期股由现金流拦截，不靠估值分位

某周期品方向四只同期 ROE 达 20%–95% 量级，**高于**某成长方向两只 —— 单看 ROE 无法区分周期顶部与真实成长。真正分界是**经营现金流**（前者全负），已是 A1/A2 必要门槛。**因此不新增估值否决项。**


## 输出与停止条件

每只标的的四项结论 + 依据产出即停；进入跟踪的转第5步 `ashare-step-5-tracking-timing`。
