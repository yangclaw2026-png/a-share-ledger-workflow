# A股一手财报取数与核实

核实 A 股上市公司的**真实业务**与**财务质量**时使用。适用于候选筛选、行业分析、持仓复核——任何不能靠概念标签或搜索摘要下结论的场景。

## When to Use

- 需要确认一家公司年报/半年报里**主营业务到底是什么**、相关业务**占营收多少**。
- 需要**现金流、扣非、分产品/分区域**等数字，而不是搜索摘要里的那几个百分点。
- 需要引用公司**自陈的风险**作为反面证据。
- 用户或流程要求“读年报核实，不凭印象”。

**不适用**：只要行情价量（用行情接口）；只要概念板块归类。

### 二、本技能专属红线

- 🔴 **「营收高增 + 经营现金流转负」是周期扩张期典型形态**，此时营收越快越该警惕。
- 🔴 **境外收入占比区分传导链**：占比极低的公司即使增速高，也**不在这条链上**，不能算进同方向候选。
- 🔴 **「短缺红利」不是可持续增长**，须写明随供给恢复而消退并给恢复信号。
- 🔴 **往上游找瓶颈**：受制于衬底/材料配额时，关键不是会做产品而是拿到配额，筛选权重从技术能力转向配额与成本曲线。
- 🔴 **PE 分位与 PB 分位必须同时看**（常给相反结论）。⚠️ 不得机械套用「PE 三成+PB 九成＝真贵」：高 ROE 成长股 PB 结构性偏高是 `PB=PE×ROE` 的数学结果。**PB 分位只作警示（🟡≥90%/🔴≥98%），不得当买入否决项。**
- 🔴 **现金流为负先分型**：备货型（存货/预付大增**且**应付与合同负债同步增）可接受；应收单独大增而合同负债不增才是质量型。
- 🔴 **用检索途中顺带看到的公司充当候选池会系统性建窄** → 按环节做独立普查；无法枚举全市场须明说「本次为抽样、可能有遗漏」。
- 🔴 **查诉讼/事件进展时逐条读标题再取原文** —— 列表会混进邻近议题。
- 全局三条硬规则见 `a-share-investment-workflow`《执行纪律》一节。

### 三、收尾自查

- [ ] 每条数据有来源、期间、单位、口径
- [ ] 扣非与归母分开，且说明了水分来源
- [ ] 现金流转负的已按备货型/质量型分型并给依据
- [ ] 一次性项目已按公司披露剔除并重算
- [ ] PB 分位只作警示，未当否决项
- [ ] 未用搜索摘要凑财务数字

## 铁律：能拿原文就不要用摘要

搜索摘要与概念标签**不可作为财务事实或业务真实性的依据**——它们常把题材当成业务、把归母净利当成主业改善。**拿到半年报 PDF 是本技能的首选路径。**

具体取数与解析步骤见 `references/parsing-recipes.md`（含定位 PDF 的可用路径、可用的 pdftotext 调用、要抓的章节与正则）。

## 要抓的章节与它们各自的用途

| 章节 | 回答什么 | 为什么不可替代 |
|---|---|---|
| **“主要业务”** | 公司到底做什么 | 唯一权威的业务定义；概念标签会骗人 |
| **风险提示** | 公司自认的脆弱点 | 最强的反面证据，公司自陈不可辩驳 |
| **主要会计数据** | 营收/归母/扣非/经营现金流 | 一次拿到四件套，避免只记住亮眼的那个 |
| **分产品 / 分区域** | 哪块业务在增长、境内外占比 | 区分“海外链”与“国内链”的唯一硬数据 |
| **研发投入占比** | 技术投入强度 | 高速行业里研发被稀释是隐忧 |

## 读这些数字时的判断规则

这几条是反复踩到的坑，读到对应形态就要标出来，不要只看增速：

- **扣非与归母必须分开。** 投资收益、公允价值变动能把亏损公司做成高增长；归母高增而扣非仍亏是最典型的陷阱。
- **“营收高增 + 经营现金流转负”是周期扩张期的典型形态**，不是个例。同一环节多家同时出现即行业现象；此时营收越快越该警惕。
- **成本增速 > 收入增速 = 毛利受压**，即使营收高增也要标出。
- **境外收入占比区分传导链。** 占比极低的公司即使增速很高，也不在这条链上，不能算进同方向的候选。
- **“短缺红利”不是可持续增长。** 供给短缺推高的毛利率要写明会随供给恢复而消退，并给出恢复信号。
- **往上游找瓶颈。** 芯片/器件公司受制于衬底、材料配额时，“有量”的关键不是会做产品，而是拿到上游配额；筛选权重应从技术能力转向配额与成本曲线。

## 输出纪律

- 每条数据标**来源、期间、单位、口径**，二手转述要标明是二手。
- 拿不到的（常见：半年报不按地区拆分收入）**如实记为待核实**，不要用相近口径顶替。
- 业务占比没有一手证据的公司，**不进候选池**，最多列“待核实观察”；披露未单列该业务的，明说“无法仅凭公开披露量化”。

## Pitfalls

- **只用搜索摘要凑财务数字。** 摘要常省略扣非与现金流，可能正好看不见要判的雷。
- **把概念/题材当业务。** 必读“主要业务”章节原文。
- **财报 PDF 解析失败就退回摘要。** 多半是调用参数问题（编码/布局），换参数重试。
- **拿概念标签当候选池依据。** 标签只用于生成假设，不用于确认业务。
- **忽略公司自陈风险。** 风险提示段是最便宜的反面证据来源。
- **看到区间值就当结论。** 媒体盘点常写“净利增幅稳定在 50% 至 100%”——这只是区间，必须回一手报告取精确值再判断。
- **只记归母净利。** 归母 +249% 与扣非 +16% 可能同时出现（投资收益、公允价值变动所致）；差额只是线索，要抓“非经常性损益项目和金额”表说清水分来源。
- **PE/PS 除法方向写反。** 是市值÷净利，不是净利÷市值；写反会静默得到 `0.0`，而格式化会把小值显示成 `0.0`，双重掩盖错误。
- **用单点倍数断言贵/便宜。** 判断依据是**当前倍数在自身历史 3–5 年的分位**，且**PE 分位与 PB 分位要同时看**——两者常给相反结论：PE 历史高值来自盈利低位的分母效应（亏钱时 PE 反而高），会把“盈利刚爆发”误读成“不贵”。⚠️ **但不得机械套用「PE 三成 + PB 九成＝真贵」**：PB 分位对高 ROE 成长股会结构性偏高（`PB = PE × ROE`），当扣非占归母≈100% 且年化 ROE 高时，PB 高位是 ROE 的数学结果而非泡沫（「盈利兑现压估值」形态）；只有 PE 低来自一次性收益或周期顶部利润、扣非与现金流不支持时，才是真陷阱。**PB 分位只作警示（🟡≥90% / 🔴≥98%），不得当买入否决项。** 完整判据见 `ashare-data-source-fallbacks` 技能的估值分位规则文件（valuation-percentile-rules）。
- **现金流为负就判恶化。** 先抓“将净利润调节为经营活动现金流量”拆解：存货/预付大增**且**应付与合同负债同步增，是备货型（有合理解释）；应收单独大增而合同负债不增才是质量型。再看减值构成是否主要为存货跌价准备。
- **用检索途中顺带看到的公司充当候选池。** 这会系统性建窄——按环节做一遍独立普查；无法枚举全市场时也要明说“本次为抽样、可能有遗漏”，并把用户或历史提到的标的回捞核一遍。
- **⛔ 业务线分化时用综合毛利率下结论。** 总毛利率是各业务线加权，会把真正在增长的那条线拉平。**先按业务线分别取毛利率与增速**，再判断哪条是引擎；某线塌陷时不说成“公司全面恶化”。
- **⛔ 整体利润被一次性项目掩盖时，不剔除就看不出经营趋势。** 大额授权/许可收入、资产处置收益会把利润表妆得很好看。**按公司披露剔除后重算商业化口径增速**；公司主动提示“一次性收入不可重复”时，以此为硬约束，**不得把授权款驱动的利润当作可持续盈利能力**。
- **⛔ 现金流为负不直接判恶化，但“公司给了理由”也不等于理由成立。** 备货型（存货/预付大增且应付与合同负债同步增）可接受；理由要能在现金流量表或附注里对上。**对不上就标待核实，不因“公司自述有合理解释”而免检。**
- **⛔ 看不到前瞻指标就只会盯当期利润。** 尽手抓**在手订单/新签订单/管线分子数/交付新化合物数**这类已锁定但未确认的量——它比营收更早反映景气拐点，是当期利润的下行领先指标；很多公司的估值逻辑其实由它而非当期营收决定。
- **⛔ 先验证“法案到底管什么方向”。** 政策风险容易被读反：拿到法案原文（govinfo 可直接 curl）后先定位**限制的对象与流向**（限制哪国资本流向哪国），再对照标的是在链路的哪一侧；主体合规与交易合规方向相反时会把风险说反。
- **⛔ 查诉讼/事件进展时，列表里会混进邻近议题的公告。** 逐条读标题再取原文，不要假设按关键词搜到的每一份都是要找的那件事；搜诉讼可能翻出同期的其他事件。
