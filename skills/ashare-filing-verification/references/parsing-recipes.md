# 取数与解析配方

## 1. 定位 PDF

**首选：巨潮官方两步查询（最可靠，任何板块都适用）**

`hisAnnouncement/query` **不带 orgId 时会静默返回 0 条**——看起来像接口坏了，其实是参数缺失。必须先查 orgId：

```bash
# 第 1 步：拿 orgId
curl -s -A "Mozilla/5.0" http://www.cninfo.com.cn/new/information/topSearch/query \
  -X POST -H "Content-Type: application/x-www-form-urlencoded" \
  --data "keyWord=<代码>&maxNum=5"
# 返回示例：[{"code":"600000","orgId":"9900007888","zwjc":"光迅科技",...}]
```

```bash
# 第 2 步：用 code,orgId 查公告（column：szse / sse）
curl -s -X POST http://www.cninfo.com.cn/new/hisAnnouncement/query \
  -H "Content-Type: application/x-www-form-urlencoded; charset=UTF-8" \
  -H "User-Agent: Mozilla/5.0" -H "Referer: http://www.cninfo.com.cn/" \
  --data "stock=<代码>,<orgId>&tabName=fulltext&pageSize=30&pageNum=1&column=<szse|sse>&category=category_bndbg_szsh&seDate=<YYYY-MM-DD>~<YYYY-MM-DD>&isHLtitle=true"
# 返回 announcements[].adjunctUrl，拼成 https://static.cninfo.com.cn/<adjunctUrl> 即为 PDF 直链
```

- `seDate` 拉宽到覆盖整个披露季（如 `2026-07-01~2026-09-30`），半年报多在 8 月下旬。
- `column` 必须按交易所给：6 开头/科创 `sse`，0/3 开头 `szse`。
- **这条路走通就不要再退回搜索**——搜索噪声大且容易只拿到区间值。

**备用：搜索定位**

```
web_search "<公司名> <代码> 2026年半年度报告 site:static.cninfo.com.cn"
```

二手财经媒体文章（每经、财新、证券时报等）逐项引述半年报原文时，可作为**补充**证据；能用一手就别用二手。

**本地已有的历史分析 PDF 常含已核实的半年报数字**，可比重新检索快；但要标明它的生成日期，并在拿到一手报告后**用一手数据覆盖**（旧报告可能只记了归母、漏掉扣非与现金流）。

## 2. 下载与解析

## 1b. 公告接口回退梯（cninfo 批量失效时用）

**“接口返空”≠“该股无此公告”。** cninfo 的 `topSearch/query` 会给一批代码**整批**返回 `orgId=None`，此时即使按 §1 带 orgId 查 `hisAnnouncement/query` 也会返回 0 条。遇到整批返空（而非单只缺参）说明是该入口当前不可用，**直接走回退，不要反复调参或据此断定数据不存在**。

| 用途 | 回退入口（已验证） |
|---|---|
| 公告列表 | 东财 `https://np-anotice-stock.eastmoney.com/api/security/ann?page_size=50&page_index=1&ann_type=A&client_source=web&stock_list={code}`（带 `Referer: https://data.eastmoney.com/`；返回 `notice_date`/`title`/`art_code`）|
| 公告 PDF | 东财 `https://pdf.dfcfw.com/pdf/H2_{art_code}_1.pdf` |
| 批量行情 | 新浪 `https://hq.sinajs.cn/list=sh600000,sz300347` |

**东财公告列表的两个要点：**

- 列表含大量干扰项（权益分派、募集资金专项、投资者关系记录…）。取半年报本体要精确匹配：`"半年度报告" in title and "摘要" not in title`，再按日期倒序取第一条。
- 同一只代码会重复返回同一条（分页重叠），按 `art_code` 去重。

**新浪行情的两个坑：**

- 必须带 `-H "Referer: https://finance.sina.com.cn"`，否则返空。
- 返回是 **GBK**，用 `o.stdout.decode("gbk","ignore")`；直接按 utf-8 解会报 `UnicodeDecodeError`。
- 字段下标：`f[0]`=名称、`f[2]`=昨收、`f[3]`=现价、`f[9]`=成交额。**涨跌幅需自己用现价/昨收算**——按位置盲取会错列。

## 1c. 未上市公司的一手文件（招股书／问询函回复）

研究拟IPO 或未上市标的公司时，一手材料在交易所披露目录，**比二手报道强得多**。用 `site:` 定位后按日期目录拼路径：

```
web_search 'site:static.sse.com.cn <公司名> 招股说明书'
→ https://static.sse.com.cn/stock/disclosure/announcement/c/{YYYYMM}/{项目号}_{YYYYMMDD}_{文件码}.pdf
```

同一项目号下的文件码不同即不同文件（招股书/问询函回复/保荐书/上市保荐书）。搜 `"{公司名} 招股说明书 pdf static.sse.com.cn"` 可拿到更新版。

**⭐ 问询函回复往往比招股书更有价值**：它是监管质疑过、公司书面答过的内容，包含公司对“某业务是否已产生商业化收入”“费用率是否高于同业”“临床数据是否可靠”的正面回应，**是核验业务真实性与财务质量的一手证据**。招股书只陈述，问询函回复才带质证。

上交所审核状态接口 `query.sse.com.cn` 可能返 `SOA service is null`，浏览器访问也可能被拒；**回退到财经媒体确认当前所处阶段（受理/问询/上会/过会/注册），并标明该进度为二手**。

⚠️ 交易所与监管站点结构会变，**不要把某个接口的当下可用性写成永久结论**，每次按上表逐级验证。

```bash
curl -sL -o x.pdf 'https://static.cninfo.com.cn/finalpage/YYYY-MM-DD/ID.PDF'
pdftotext -layout -enc UTF-8 x.pdf x.txt
```

- `-enc UTF-8` 必加，否则中文输出异常。
- 解析没产出先看是不是缺 `-enc UTF-8` 或漏了 `-layout`，而不是直接换工具。
- 本环境通常只有 poppler 的 `pdftotext`；不需要额外装 PDF 库。

## 3. 抓关键段落（正则起手式）

```python
import re
c = open("x.txt", encoding="utf-8", errors="ignore").read()

for kw in [r"公司主要从事", r"主营业务为", r"主要产品",
           r"风险", r"客户集中", r"境外", r"分产品", r"分地区", r"经营活动产生的现金流量净额"]:
    for m in list(re.finditer(kw, c))[:2]:
        s = max(0, m.start() - 200)
        print(kw, "::", c[s:m.start()+600].replace("\n", " "))
```

- 用 `[:2]` 限量打印，避免把整份半年报灌进上下文。
- `-layout` 输出的数字可能带空格，逐字引用时**复制原文片段**而不是重打。

## 4. 一次拿全“四件套”

主要会计数据表通常在一页内同时给出营收、归母净利、**扣非**、**经营活动现金流净额**及同比。抓这一页即可覆盖大部分判断需求，务必四个都看。

## 5. 估值计算（PE/PS 方向写反是最常见的错）

**方向：PE = 市值 ÷ 年化净利，PS = 市值 ÷ 年化营收。分母是价格。** 写成“净利÷市值”会得到 `0.0x` 这类荒谬值。

```python
mc_yuan  = price * shares          # shares 从财报“股份总数/股本总额”取，不用外部估算
pe = mc_yuan / (h1_net_profit * 2)
ps = mc_yuan / (h1_revenue  * 2)
```

- **`H1 × 2` 年化是乐观口径**——当期增速若不可持续，实际倍数更高，结论里必须标注。
- **格式化会把错误藏起来**：小数值用 `f"{v:>9.1f}"` 打印会显示 `0.0`，看上去像公式错了。先用一个已知参照物验算公式方向，再批量跑。
- **股价/市值极端值先排“除权”**：面值高达数百元、股本小，常见于高送转后未复权；用财报股本×现价反推市值再对照公司总市值自洽。
- **单点倍数不等于贵/便宜。** 判断依据是当前倍数在自身历史 3–5 年的**分位**；取不到分位就明写“估值检查的核心缺口”，不要用单点倍数下结论。**分位可以直接算，见《5a》。**

## 5a. 历史估值分位（东财 datacenter，行情列表接口不通时用它）

`push2.eastmoney.com/api/qt/clist` 取不到数据时，**datacenter 与 push2his 是可用的**——不要因为前者不通就宣布“拿不到分位”：

```bash
# 历史 PE/PB/市值：pageSize=500 循环 pageNumber 即可拉全历史
curl -s --compressed -H "Referer: https://quote.eastmoney.com/" \
 "https://datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_VALUEANALYSIS_DET&columns=SECURITY_CODE,TRADE_DATE,PE_TTM,PB_MRQ,TOTAL_MARKET_CAP&filter=(SECURITY_CODE%3D%22600001%22)&pageSize=500&pageNumber=1&sortColumns=TRADE_DATE&sortTypes=-1&source=WEB&client=WEB"

# 日K（前复权，500日）→ 算 MA/RSI/MACD
curl -s --compressed -H "Referer: https://quote.eastmoney.com/" \
 "https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=1.600001&fields1=f1,f2&fields2=f51,f52,f53,f54,f55,f56,f57&klt=101&fqt=1&lmt=500"
# secid 前缀：沪市/科创 1.，深市 0.
```

**PE 分位与 PB 分位必须同时算，两者会给出相反结论。** PE 历史高值往往来自盈利低位的**分母效应**（公司亏钱时 PE 反而高），单看 PE 会把“盈利刚爆发”误判成“不贵”。⚠️ **但「PE 分位三成 + PB 分位九成」不必然是真贵**：PB 分位对高 ROE 成长股会结构性偏高（`PB = PE × ROE`），当扣非占归母≈100% 且年化 ROE 高时，PB 高位是 ROE 的数学结果而非泡沫——这就是「盈利兑现压估值」形态（PB 高、但 PE 近 1 年分位落到个位数）。**只有 PE 低来自一次性收益或周期顶部利润、扣非与现金流不支持时，才是真陷阱。** PB 分位只作警示（🟡≥90% / 🔴≥98%），不作买入否决项；判据见 `ashare-data-source-fallbacks` 技能的估值分位规则文件。

**⚠️ 上传新股会污染长期分位，先查再报。** 上市首年净资产小，PB 可达 40~50 倍、PE 几百倍，混进全历史会把当前分位压低。做法：定位历史样本里的极端高值，**回查它们集中在哪一年**；若集中在上市首年，剔除首年重算，并在结论里写明“重算后分位与原分位是否一致”。**一致才说明数据稳健，差异大则必须双口径并列。**

**⛔ “股价跌了一半”与“估值变便宜”是两件事。** 股价回落而PB分位仍在90%+，说明跌掉的是此前炒高的溢价，**估值本身并不便宜**。判断买不买看分位，不看距高点的跌幅。

**⭐ 归因：PB分位低 + 60日大涨并不矛盾。** 低PB分位（如<40%）与高60日涨幅（如+40%以上）同时出现，说明**涨幅由业绩增长驱动而非估值扩张**。反之（PB分位90%+ 同期大涨）**要分两种**：同期扣非与经营现金流同向高增的是「盈利兑现压估值」的成长形态（合理）；**无业绩支撑的才是纯投机、脆弱**。**判据是业绩，不是分位数字本身。** 把PB分位、区间涨跌与扣非/现金流并排呈现，是区分“业绩牛”与“估值牛”最快的方法。

**判定除权**：扫相邻交易日收盘价跳变 >40%，再回巨潮查《权益分派实施公告》，用公告给出的除权参考价公式 `(前收盘价−每股现金红利)÷(1+流通股份变动比例)` 验算，而不是靠猜。股价面值高（数百元）且当日无重大消息，多半是高送转未复权。

## 6. 归母与扣非差额归因（差额方向只是线索，来源要落到明细）

“归母高增而扣非弱”只能提示有水分，**要说清水分是什么**，需抓“**非经常性损益项目和金额**”表：

```python
import re
i = c.find("非经常性损益项目和金额")
print(re.sub(r"\s+", " ", c[i:i+700]))
```

常见大项：金融资产/负债公允价值变动及处置损益、政府补助、股权收购重估收益。**逐项加总可验证差额是否被解释完整**，解释不了的余额往往本身就是风险（如一次性处置收益）。

## 7. 现金流为负：先拆解，再判定性质

经营现金流为负**不等于**经营恶化，也不等于坏账。必须抓现金流量表补充资料的“**将净利润调节为经营活动现金流量**”逐项拆：

```python
i = c.find("将净利润调节为经营活动现金流量")
print(re.sub(r"\s+", " ", c[i:i+900]))
```

重点看三行：**存货的减少 / 经营性应收项目的减少 / 经营性应付项目的增加**，再回资产负债表核对期末数（存货、预付款项、应收账款、应付账款、合同负债）。

- **备货型（可接受）**：存货与预付款项大增，同时应付账款与合同负债也在增 → 钱进来了但先变成库存，对应“订单已收、产能扩张中”。**结论应写“有合理解释”，可上调评级**。
- **质量型（危险）**：应收账款单独大增、合同负债不增 → 回款能力或客户质量恶化。
- 若二者同时存在，**再查减值构成**：资产减值常主要是存货跌价准备，说明已经开始计提，才是真的风险信号。

## 7b. 分业务线取毛利率：综合数会拉平真相

公司同时经营多条业务线时，**只用总毛利率会把真正在增长的那条线拉平**。每条业务线分别取毛利率＋同比＋收入增速，才能看出谁是引擎：

```python
i = c.find("毛利率情况如下")
print(re.sub(r"[ \t]+", " ", c[i:i+900]))
```

- **某条线毛利率暴涨而另一条持平/微降，是常态**（结构升级＋周期位置不同）。只报总数会把“有增长引擎”说成“全面向好/全面恶化”。
- 定位到引擎后，**整段分析要围着它转**（某CRO的增长来自化学业务而非生物业务时，生物线的疲软不构成公司级利空）。

## 7c. 剔一次性项目后重算经营口径

大额授权/许可首付款、资产处置收益会把利润表妆得好看。**公司主动提示“一次性收入不可重复”时，以此为硬约束，不得把授权款驱动的利润当作可持续盈利能力。**

- 公司通常**不单独披露授权收入金额**，需自己反推：从归母与扣非的差额入手，或用“总营收 − 已知分项”估算，并**明确标注为估算**。
- 算完给出**剔除前 / 剔除后**两个增速，并写明商业化口径的真实同比。差距很大时，**利润的可持续性判断以剔除后为准**。

## 7d. 抓前瞻指标：在手订单 / 新签订单 / 管线数

当期利润是滞后的，**在手订单、新签订单、管线分子数、交付新化合物数这类“已锁定未确认”的量更早反映景气拐点**，很多公司的估值逻辑由它而非当期营收决定。必查并在台账里单列为可观察指标。

## 8. 拿不到时的处理

| 缺口 | 常见原因 | 处理 |
|---|---|---|
| 境外收入占比 | 半年报未按地区拆分 | 记为待核实；找投资者关系纪要或第三方转述，并标明二手 |
| 业务占比 | 主营未单列该业务 | 明说“无法仅凭公开披露量化”，不进候选池 |
| 现金流 | 摘要里省略 | 必回一手 PDF 抓 |

**不要用相近口径顶替缺失数据。**
